## Mechanism

Use untouched pretrained Pythia410M in FP32. Every layer/head has four independent trainable raw keys and four trainable full value vectors. Keys/values are initialized by capturing the per-layer KV generated by the first four tokens of the PG19 **training** stream. No test tokens determine the universal initialization. All original model parameters remain frozen; only196608 KV parameters train. This is a direct learned KV prefix, related to [prefix tuning](https://arxiv.org/abs/2101.00190), not a claim of a novel attention mechanism.

The four virtual keys occupy RoPE positions0..3; their value vectors are not rotated. Queries and recent physical keys use cache-relative positions after the prefix. Normal1/sqrt(head_dim) scaling and a single softmax normalize the virtual and physical keys together. No extra learned sink-score bias, tiny value initialization, near-zero mass calibration, zero-value constraint or separate query-conditioning MLP is used. Query conditioning is ordinary dot-product attention against the learned keys.

Memory slots are permanent and count against the1024-entry saved cache: four virtual plus1020 recent real entries. Each new prediction transiently sees at most1025 total entries, then trims the oldest real key/value. Prefix values participate in the attention numerator, not merely its denominator. The one theoretical difference remaining versus real StreamingLLM tokens is that universal learned KV is shared across streams, whereas real initial-token KV depends on that stream's first four tokens. Capturing exact per-stream prefix KV would simply reproduce the physical-token method.
